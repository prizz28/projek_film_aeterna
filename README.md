# Aeterna - Website Katalog Film

Aeterna adalah website katalog film dengan konsep dark cinematic yang dibuat menggunakan HTML, CSS, dan JavaScript. Website ini digunakan untuk menampilkan informasi film serta menyediakan beberapa fitur interaktif bagi pengguna.

## Fitur Utama

- Katalog film
- Pencarian film
- Filter berdasarkan genre
- Pengurutan berdasarkan rating
- Halaman detail film
- Menampilkan trailer film
- Watchlist film
- Responsive untuk desktop, tablet, dan mobile

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Figma
- GitHub Pages
